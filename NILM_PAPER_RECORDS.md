## Topic Notes

### A non-intrusive load monitoring system using multi-label classification approach

The topic of this paper is **non-event-based, low-frequency NILM using multi-label machine learning classification**. It treats appliance disaggregation as a multi-output classification problem, where each one-minute aggregate electrical sample is mapped to several appliance ON/OFF labels at the same time.

The main idea is that multiple appliances can be active simultaneously, so NILM should not always be modeled as separate single-label classification tasks. The paper compares multi-label methods and finds that **RAkEL with a C4.5 Decision Tree** gives the best practical balance between F-score and prediction speed. The final selected input features are **current, real power, reactive power, and power factor**.

The paper is useful for this project because it gives a clear baseline for low-frequency NILM: use aggregate electrical features, build multi-label appliance state labels from sub-metered circuit data, train a supervised classifier, and evaluate with F-score and classification accuracy.

### Multilabel Appliance Classification With Weakly Labeled Data for Non-Intrusive Load Monitoring

This paper is directly relevant to the project's planned mini NILM because it uses **one deep multi-label model** to predict several appliance ON/OFF states from aggregate power. The network output is a vector of appliance probabilities rather than one single class, so it naturally supports cases such as `[1, 1, 0, 0, 0]`, where multiple appliances are active at the same time.

The proposed model is a CRNN trained with both strong and weak labels. Strong labels are sample-level appliance states, while weak labels only say whether an appliance appears somewhere inside an aggregate power segment. This is formulated as a Multiple-Instance Learning problem. The architecture produces both instance-level predictions and bag-level predictions, then uses clip smoothing to make segment-level and sample-level predictions more coherent.

For our work, the most important takeaway is not the weak-label part yet, but the formulation:

```text
aggregate feature/power sequence -> multi-label appliance ON/OFF vector
```

This supports building our mini NILM as a single neural multi-label classifier with sigmoid outputs for all appliances. The paper also supports evaluating with per-appliance F1 and micro-F1, and it shows that low-frequency sequence models can be trained on full datasets with OFF and ON states rather than only ON-only periods.

### Selection of Features Based on Electric Power Quantities for NILM

This paper is useful for our feature-selection argument because it does not only rank features mathematically. It ranks candidate features, then checks whether the selected subset actually improves an NILM classifier. That matches our planned idea: feature selection should be trusted only when the mini NILM itself performs well.

The feature design is event-based. Around each detected switching event, the authors compute power-quantity changes before and after the event. The important point is that the same quantity at different post-event time windows can carry different information, so their selected features are not only "which electrical quantity", but also "which time step after the event".

The main result is that **NCA worked better than mRMR for selecting a compact feature subset in this paper**. NCA suggested that the top 8 features were enough, and adding more features did not improve the MLP. mRMR ranked the features, but it did not provide a meaningful stopping point because its cumulative score did not clearly saturate.

For our project, this paper supports using feature ranking as a pre-screening stage, but it also warns us not to trust mRMR alone. The stronger experimental design is:

```text
candidate features -> ranking/filtering -> mini NILM validation -> final selected feature subset
```

This paper is not the same as our final target because it is event-based multi-class classification, while our current direction is full-timeline multi-label appliance ON/OFF detection. Still, its feature-selection logic is relevant: the selected feature subset must be justified by downstream NILM performance, not only by a filter score.

### NILMFormer: Non-Intrusive Load Monitoring that Accounts for Non-Stationarity

The topic of this paper is **handling non-stationarity (distribution drift) in low-frequency sequence-to-sequence NILM using a Transformer-based architecture**. It addresses the issue that statistical properties (mean and standard deviation) of aggregate power sequences change dramatically depending on which high-consuming appliances are active at any given moment.

The paper makes three main contributions:
1. **Subsequence Stationarization and De-stationarization**: The input aggregate subsequence is z-normalized to remove its mean and standard deviation. These statistics are linearly projected into a `TokenStats` vector and appended as a token to the Transformer input. After the self-attention layer mixes the representations, the output `TokenStats` token is projected via `ProjStats` to predict the denormalization parameters (mean and std) of the target appliance power sequence. This prevents "over-stationarization" (loss of scale information) while keeping input distributions stable.
2. **Timestamp-Related Positional Encoding (TimeRPE)**: Instead of standard or learnable positional encodings, it decomposes timestamps into discrete components (minutes, hours, days, months) and maps them using sinusoidal bases. This information is concatenated (which performs better than addition) to help the model learn time-of-use patterns (e.g. charging EVs at night).
3. **Large-scale evaluation and deployment**: Evaluated on public (UKDALE, REFIT) and private (EDF 1, EDF 2) datasets, showing significant improvements (15% in MAE, 22% in Matching Ratio) over SotA. The model was successfully deployed by EDF for their *Mon Suivi Conso* service, serving millions of users.

For our project:
* The paper provides strong support for using time-of-day/day-of-week contextual features (similar to the timestamps in TimeRPE) to help identify cyclic appliance usage.
* It demonstrates that sequence-to-sequence learning on raw power values requires careful normalization because of distribution shifts.
* It shows that although disaggregation models can be trained per-appliance (single-target regression), their outputs are combined at a level above to perform multi-appliance energy estimation.

### Conv-NILM-Net, a causal and multi-appliance model for energy source separation

The topic of this paper is **real-time, multi-appliance energy source separation (regression) using a fully convolutional neural network**. It adapts the speech-separation model **Conv-TasNet** to perform low-frequency NILM disaggregation, outputting power waveforms for multiple appliances simultaneously from a single joint model.

The paper highlights two key challenges in deep learning-based NILM:
1. **Multi-Appliance Scaling:** Training separate single-task networks for each appliance is computationally expensive and ignores correlations between appliances. Conv-NILM-Net addresses this by estimating $C$ masks (one for each appliance) in a shared latent space and disaggregating all appliances in one forward pass.
2. **Causality:** Many state-of-the-art models (like seq2point or UNet-NILM) are non-causal (i.e. they require look-ahead/future data), making them unsuitable for real-time edge deployment. Conv-NILM-Net ensures causality using asymmetric padding in the 1D dilated convolutions of its Temporal Convolutional Network (TCN).

Key structural design choices:
* **GLUs (Gated Linear Units):** Replaced LeakyReLUs in the TCN blocks because appliance activations are highly dependent (unlike independent human speakers in speech separation). GLUs allow the model to learn complex inter-appliance dependencies.
* **Summed Loss (WMSE):** Rather than averaging the Mean Squared Error across all appliances, it sums the errors. Averaging distributes errors across appliances, which causes high-power appliance signals (like heaters) to leak as "ghost artifacts" into low-power predictions (like fridge). Summing the error prevents this cross-talk.
* **Low Parameter Count:** Achieves state-of-the-art results with only 41K parameters—dramatically smaller than models like seq2point (29.2M) or UNet-NILM (2.4M).

For our project:
* Illustrates the exact design of a **joint multi-appliance model** that predicts all appliances in one go.
* Provides a blueprint for keeping neural models **causal** (no look-ahead) for real-time disaggregation.
* The choice of **summing losses** rather than averaging is an important training trick to prevent high-power appliance features from polluting low-power appliance predictions during multi-target learning.
